# 发布检查清单

在上传图片和调用 YESCMS 发布接口前，逐项检查。

## 视频证据

- 已读取完整字幕或完成整段音频转写。
- 下载的非简体中文字幕已完整翻译为 `<视频标题>.zh-Hans.vtt`，并与原字幕保存在同一视频目录。
- 简体中文字幕保持原时间轴、UTF-8 编码和有效 `WEBVTT` 结构；原字幕文件未被覆盖。
- 简体中文字幕已检查漏译、残留说明性外语、时间轴损坏和编码乱码。
- 已记录视频总时长和主要章节时间点。
- 已区分“议程提到”和“正文实际讲解”。
- 文章中的示例编号、组织单位、物料类型和事务码都能回溯到视频时间点。

## SAP 事实

- 只用 SAP Learning、SAP Help 或其他 SAP 官方页面校验标准行为。
- 把客户配置、课程系统配置和讲师经验写成示例，不写成全球固定规则。
- 对组织层级、主数据视图、字段可修改性、编号范围和估价行为做过复核。
- 官方补充没有伪装成视频原话。

## 图片

- 第一张图片是文章封面或概览图。
- 原始软件截图保持源分辨率，优先使用 1920×1080 PNG。
- 截图没有模糊、无意义空白、系统报错、遮挡或无关窗口。
- 除 SAP GUI 或 SAP Fiori 界面截图外，其他图片全部重新制作，没有直接使用视频原图。
- 重做图片中的标题、正文、标签、图例和注释等可翻译文字已全部翻译为中文。
- `MM01`、`ROH`、SAP 产品名、字段代码和组织代码等必要标识可以保留，必要时已补充中文说明。
- 重做图片没有改变原始信息关系和含义，也没有冒充 SAP 软件界面。
- 所有图片均上传成功且关闭压缩。

## 标题和正文

- 视频序号符合用户要求；两位格式示例为 `04`。
- 标题格式为 `SAP S/4HANA MM模块培训 NN - 主题`，除非用户另有明确规则。
- Markdown 第一行是已上传的封面图片。
- 正文包含课程目标、核心概念、操作步骤、易错点、课程边界和参考资料。
- 图片紧跟对应步骤，不在文章末尾集中堆放。
- 没有把未讲内容、未来课程或推测写成本课成果。

## YESCMS 发布参数

| 字段 | 要求 |
|---|---|
| `category` | 使用已确认的类目 slug；既定 SAP 类目为 `sap` |
| `title` | 与正文主题和用户命名规则完全一致 |
| `coverImageUrl` | 使用第一张已上传图片 |
| `imageUrls` | 包含正文使用的全部已上传图片，封面排第一 |
| `markdown` | 第一行必须是封面图 |
| `originUrl` | 原始 YouTube 视频 URL |
| `summary` | 一句话概括本课具体内容 |
| `seoKeywords` | 约 8–12 个具体关键词 |
| `tagList` | 3–8 个标签 |
| `isPublished` | 用户要求直接发布时为 `true` |
| `isTop` | 默认 `false`，除非用户明确要求置顶 |

## 发布后

- CMS 返回成功状态、文章 ID 和公开 URL。
- 公开页面返回 HTTP 200。
- HTML 中能找到精确标题、封面文件名和正文关键词。
- `CONTEXT.md` 已记录本次发布及本地素材目录。
